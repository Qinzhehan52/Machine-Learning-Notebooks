# 1. 监督机器学习：回归和分类

在机器学习专项课程的第一门课程中，你将：

• 使用流行的机器学习库 NumPy 和 scikit-learn 在 Python 中构建机器学习模型。

• 构建并训练用于预测和二元分类任务的监督机器学习模型，包括线性回归和逻辑回归

机器学习专项课程是 DeepLearning.AI 和 Stanford Online 合作创建的基础在线项目。在这个初学者友好的项目中，你将学习机器学习的基础知识，以及如何使用这些技术构建现实世界的 AI 应用程序。

该专项课程由 Andrew Ng 讲授，他是一位 AI 远见者，曾在斯坦福大学领导关键研究，并在 Google Brain、百度和 Landing.AI 开展开创性工作，推动 AI 领域的发展。

这个包含 3 门课程的专项课程是 Andrew 开创性的机器学习课程的更新和扩展版本，该课程自 2012 年推出以来，评分为 4.9 分（满分 5 分），已有超过 480 万学习者参加。

它提供了对现代机器学习的广泛介绍，包括监督学习（多元线性回归、逻辑回归、神经网络和决策树）、无监督学习（聚类、降维、推荐系统）以及硅谷用于人工智能和机器学习创新的最佳实践（评估和调整模型、采用以数据为中心的方法来提高性能等）。

在本专项课程结束时，你将掌握关键概念并获得实用的专业知识，能够快速有力地将机器学习应用于具有挑战性的现实世界问题。如果你想进入 AI 领域或建立机器学习职业生涯，新的机器学习专项课程是最好的起点。
