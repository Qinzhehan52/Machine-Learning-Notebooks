通过免费旁听的 [机器学习专项课程][MACHINE_LEARNING_SPECIALIZATION_URL] 进入 AI 领域。
在这个由 AI 远见者 Andrew Ng 开发的初学者友好的 3 门课程项目中，掌握基本 AI 概念并开发实用的机器学习技能。

**你将学到什么：**
- **使用 NumPy 和 scikit-learn 构建机器学习模型**  
  - 构建并训练用于预测和二元分类任务的监督模型（线性、逻辑回归）

- **使用 TensorFlow 构建并训练神经网络**  
  - 执行多类分类  
  - 构建并使用决策树和树集成方法  

- **应用机器学习开发的最佳实践**  
  - 使用无监督学习技术，包括聚类和异常检测  

- **构建推荐系统**  
  - 使用协同过滤方法  
  - 实现基于内容的深度学习方法  
  - 构建深度强化学习模型  


## 🚀 模块 🚀

### 课程 1 - [监督机器学习：回归和分类][SUPERVISED_LEARNING_COURSE_URL]

在机器学习专项课程的第一门课程中，你将：

- 使用流行的机器学习库 NumPy 和 scikit-learn 在 Python 中构建机器学习模型。
- 构建并训练用于预测和二元分类任务的监督机器学习模型，包括线性回归和逻辑回归

### 课程 2 - [高级学习算法][ADVANCED_LEARNING_COURSE_URL]

在机器学习专项课程的第二门课程中，你将：

- 使用 TensorFlow 构建并训练神经网络以执行多类分类
- 应用机器学习开发的最佳实践，使你的模型能够泛化到现实世界的数据和任务
- 构建并使用决策树和树集成方法，包括随机森林和提升树

### 课程 3 - [无监督学习、推荐系统、强化学习][UNSUPERVISED_LEARNING_COURSE_URL]

在机器学习专项课程的第三门课程中，你将：

- 使用无监督学习技术进行无监督学习：包括聚类和异常检测。
- 使用协同过滤方法和基于内容的深度学习方法构建推荐系统。
- 构建深度强化学习模型。
